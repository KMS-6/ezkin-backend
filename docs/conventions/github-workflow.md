# GitHub 협업 워크플로

## 1. 브랜치 구조

```text
feature/be/* → develop → main
```

- `feature/be/*`: 기능과 문서, 설정 작업 브랜치
- `develop`: 팀 개발 통합 브랜치
- `main`: 최종 제출과 배포 기준 브랜치

`develop`과 `main`에는 직접 push하지 않고 PR로만 병합한다.

## 2. Ruleset

### main

- PR 필수
- 최소 1명 승인 필수
- `Backend`, `Deployment config` 통과 필수
- 모든 리뷰 대화 해결 필수
- force push와 브랜치 삭제 금지

### develop

- PR 필수
- 승인 0명: 해커톤 개발 속도를 유지하되 PR과 CI는 강제
- `Backend`, `Deployment config` 통과 필수
- 모든 리뷰 대화 해결 필수
- force push와 브랜치 삭제 금지

Ruleset은 해당 저장소의 **Settings > Rules > Rulesets**에서 화인한다.

## 3. Issue

- `[타입] 작업 내용` 형식을 사용한다.
- 기능, 버그, 문서·설정 템플릿 중 작업에 맞는 형태를 선택한다.
- 작업 전 목적, 내용, 완료 기준을 명화게 작성한다.

## 4. Pull Request

- PR 하나는 하나의 목적만 가진다.
- 관련 Issue을 `Closes #이슈번호`로 연결한다.
- 결정 이유, 검증 결과, AI 사용 범위, 리뷰 포인트를 작성한다.
- 제목은 `[타입] 작업 내용` 형식을 사용한다.

세부 코드 리뷰 규칙은 [PR 크기·코드 리뷰 컨벤션](code-review.md)을 따른다.
