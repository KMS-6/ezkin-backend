# ADR 002: Vision 입력은 비식별화 후 전송하고 모델 메타데이터를 영속화한다

## 상태

Accepted

## 배경

카메라 스캔은 얼굴 사진을 외부 Vision API에 전송한다. 업로드 원본에는 EXIF 위치·기기
정보가 포함될 수 있고, 현재 저장 구조는 분석 당시 모델 정보를 보존하지 않으면 설정 변경 후
과거 결과의 출처를 정확히 재현할 수 없다.

## 결정

JPEG와 PNG 입력은 Pillow로 디코딩한 뒤 새 이미지로 재인코딩해 EXIF를 제거하고, 이
정규화된 바이트만 Anthropic Vision API에 전송한다. 원본과 정규화 이미지는 분석 후
보관하지 않는다. 분석이 완료된 스캔에는 provider, 모델명, 모델 버전과 관찰 스키마 버전을
PR #40에서 정의한 컬럼에 저장한다.

## 고려한 대안

- 원본을 저장한 뒤 비동기 삭제: 재처리가 쉽지만 삭제 실패와 보관 기간 동안 개인정보 노출
  위험이 남는다.
- EXIF 세그먼트만 제거: 구현은 가볍지만 손상되거나 조작된 이미지의 실제 디코딩 여부를
  검증하지 못한다.
- 조회 시 현재 모델 설정을 표시: 추가 저장은 없지만 과거 결과의 출처를 잘못 표시한다.

## 결과와 트레이드오프

- 원본 EXIF가 외부 API와 로컬 저장소에 남지 않는다.
- 이미지 디코딩·재인코딩 비용과 Pillow 런타임 의존성이 추가된다.
- 원본을 보관하지 않으므로 동일 이미지 재분석은 사용자가 다시 업로드해야 한다.
- 모델 설정이 변경되어도 과거 스캔의 생성 모델과 스키마를 정확히 조회할 수 있다.
